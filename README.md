# Flash-Manga — Paperback iOS Extension 📱📖

This is a custom extension for the **[Paperback](https://paperback.moe)** iOS manga reader app that fetches manga, chapters, and high-quality images from **[flash-manga.net](https://www.flash-manga.net)** (Thai translations).

---

## ✨ Features

- 🏆 **Top Popular Manga**: Shows the top 5 trending manga directly on your home screen.
- ⚡ **Latest Updates**: Displays the newly released chapters in real-time.
- 🔍 **Search & Filters**: Search for any manga title in Thai or English.
- 📜 **Full Chapter Reader**: High-resolution chapter image loading with fast decryption & zero ads.
- 🔄 **Pagination & View More**: Browse complete catalog pages seamlessly.

---

## 🚀 How to Install on your iPhone / iPad (No Coding Required!)

### Step 1: Upload Files to GitHub
1. Create a new repository on [GitHub](https://github.com/new) (e.g. named `paperback-sources`). Make sure it is set to **Public**.
2. Upload all files from this folder into your repository and commit them to the `main` branch.

### Step 2: Enable GitHub Pages (Using GitHub Actions)
1. In your GitHub repository, click on **Settings** (⚙️) at the top.
2. Click on **Pages** in the left sidebar menu.
3. Under **Build and deployment > Source**, change the dropdown from *Deploy from a branch* to **GitHub Actions**.
4. That's it! GitHub Actions will automatically build and publish your extension within 1-2 minutes.

### Step 3: Add to Paperback App
1. Open the **Paperback** app on your iPhone or iPad.
2. Go to **Settings** (⚙️) > **External Repositories**.
3. Tap **Add Repository** and enter your GitHub Pages URL:
   ```text
   https://<your-github-username>.github.io/<repo-name>/
   ```
4. Tap **Save**. You will now see **Flash-Manga** in the extension list!
5. Tap **Install** next to Flash-Manga and start reading! 🎉
